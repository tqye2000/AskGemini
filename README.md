# AskGemini

A web interface to Google Gemini models. The model selector includes Gemini 3.1
Pro Preview, Gemini 3 Flash Preview, Gemini 3.1 Flash-Lite Preview, and Gemini
3.1 Flash Image Preview. Gemini 3 Flash is the default.

Configure `api_key` in Streamlit secrets with your Gemini API key.

Please try: https://geminiecho.streamlit.app
